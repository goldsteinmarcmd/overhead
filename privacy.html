Privacy

Last updated: 30 July 2026

What this site is

Overhead is a static visualization of Earth-orbiting satellites hosted on GitHub Pages. Address lookup uses OpenStreetMap Nominatim. Satellite imagery browse frames use NASA GIBS. Those services receive the requests your browser makes when you use those features.

Optional analytics

If you click Accept on the consent banner, Overhead sends first-party analytics events to a collector we operate on Google Cloud (Cloud Run + BigQuery, region europe-west1). This is not Google Analytics advertising products. We do not sell data or show ads.

With consent we may record:

  • Page views, session and engagement timing
  • Referrer and UTM campaign parameters
  • Approximate device class, browser, and OS
  • Country derived from IP in memory (raw IP is not stored)
  • In-app events such as selecting a satellite, searching, or zooming to a place (search text is not stored—only that a search occurred)

A random client id is stored in your browser’s localStorage after consent. If you click Decline, we send no analytics beacons and store only your choice.

Legal basis (GDPR)

Analytics run only with your consent (Art. 6(1)(a) GDPR / ePrivacy). You can withdraw anytime: clear site data for this origin, or .

Processor

Google Cloud acts as a data processor under Google’s Cloud Data Processing Addendum. Data is stored in the European Union (europe-west1) when possible.
